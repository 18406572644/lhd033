## 1. 产品概述

简易胶卷照片调色预览模拟器 — 面向摄影爱好者与胶片爱好者的纯前端调色工具，内置经典胶卷滤镜预设，支持亮度/对比度/色温/颗粒感等参数调节，提供本地图片上传实时预览、方案命名保存与导出功能，以复古胶片质感视觉风格呈现沉浸式调色体验。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客 | 无需注册 | 使用全部功能（纯前端本地运行） |

### 2.2 功能模块
1. **编辑器页面**：图片上传、实时预览、胶卷滤镜预设切换、自定义参数调节（亮度/对比度/色温/颗粒感）、方案一键重置与导出
2. **案例库页面**：经典胶片风格案例参考、已保存调色方案管理（查看/加载/删除）

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 编辑器页面 | 图片上传区 | 拖拽或点击上传本地图片，支持 JPG/PNG/WebP 格式 |
| 编辑器页面 | 实时预览区 | 左右对比展示原图与调色效果，Canvas 渲染实时预览 |
| 编辑器页面 | 滤镜预设栏 | 横向滚动展示 8 款经典胶卷滤镜缩略图，点击即时应用 |
| 编辑器页面 | 参数调节面板 | 亮度(0-200)/对比度(0-200)/色温(-100~100)/颗粒感(0-100)滑块调节 |
| 编辑器页面 | 方案操作栏 | 重置参数、保存方案（命名）、导出效果图下载 |
| 案例库页面 | 经典胶片案例 | 展示 6 款经典胶片风格案例卡片（胶卷名/风格描述/效果样图） |
| 案例库页面 | 我的方案 | 展示已保存的调色方案列表，支持加载到编辑器/删除 |
| 全局 | 主题切换 | 暗黑/浅色双主题切换按钮，动画过渡自然 |
| 全局 | 导航栏 | 页面路由切换、品牌标识 |

## 3. 核心流程

用户进入编辑器 → 上传本地图片 → 选择胶卷滤镜预设或手动调节参数 → 实时预览调色效果 → 满意后命名保存方案 → 可前往案例库查看经典参考与已保存方案 → 一键导出效果图下载

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：暖调怀旧色系 — 琥珀棕(#C4956A)、复古橙(#D4845A)、奶油白(#FAF0E6)
- **辅助色**：深棕(#3E2723)、暖灰(#8D7B68)、胶片黑(#1A1614)
- **强调色**：金色(#D4A853)
- **按钮风格**：圆角胶囊按钮，微投影，hover 时暖光晕扩散效果
- **字体**：标题使用 Playfair Display 衬线体，正文使用 Noto Sans SC，营造复古文艺质感
- **布局风格**：顶部导航 + 左侧预览区 + 右侧控制面板，胶片边框装饰元素
- **图标风格**：lucide-vue-next 线性图标，搭配胶卷/相机相关装饰性 SVG 图案
- **特殊视觉元素**：胶片齿孔边框、胶卷暗盒纹理、相纸颗粒噪点叠加、柔光晕影效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 编辑器页面 | 图片上传区 | 虚线边框拖拽区，胶片齿孔装饰，暖色渐变背景，上传图标+提示文字 |
| 编辑器页面 | 实时预览区 | 大面积 Canvas 画布，胶片边框装饰，原图/效果图对比滑块 |
| 编辑器页面 | 滤镜预设栏 | 横向滚动胶卷条样式，圆形缩略图+胶卷名称标签，选中金色边框 |
| 编辑器页面 | 参数调节面板 | 木质纹理背景卡片，自定义暖色滑块，数值实时显示 |
| 编辑器页面 | 方案操作栏 | 胶囊按钮组，重置/保存/导出三按钮，hover 暖光效果 |
| 案例库页面 | 经典胶片案例 | 瀑布流卡片布局，胶片边框效果，案例图片+名称+描述 |
| 案例库页面 | 我的方案 | 列表式卡片，缩略图+方案名+参数摘要，操作按钮 |
| 全局 | 导航栏 | 半透明毛玻璃效果，胶卷品牌 Logo 风格标题，主题切换开关 |

### 4.3 响应式设计
- 桌面优先设计，大屏双栏布局（预览区+控制面板）
- 平板端自适应缩小，控制面板折叠为底部抽屉
- 移动端单栏布局，上下滑动浏览预览与参数

### 4.4 主题设计
- **浅色主题**：奶油白底色，暖棕色调，模拟复古相纸质感
- **暗黑主题**：深棕黑底色，琥珀色点缀，模拟暗房环境氛围
- 切换时渐变过渡动画，整体色温冷暖联动变化
